ONE WORKFLOW

予定を作るところから、Discordに届くところまで。

Reactusは「設定用Bot」と「カレンダー通知」を別々に扱わず、ひとつの運用フローとしてつなぎます。

01

管理画面で作る

通常投稿や抽選、本文、画像、メンション、繰り返し条件を日本語フォームから設定します。

→
02

Calendarで管理

予定はGoogle Calendarと連携。日付を見ながら確認し、Reactusから編集・移動できます。

→
03

Discordへ届ける

指定時刻に投稿。定期告知も複数景品の抽選も、毎回手作業で投稿する必要はありません。

FEATURES

Discord運用で繰り返す作業を、まとめて任せる。

▣

予約・定期投稿

日・週・月・年単位の繰り返し、複数曜日、月末、第N曜日、終了日・回数指定まで管理画面から設定できます。

◇

複数景品の抽選

ひとつの予定に複数景品をまとめて登録。開始時刻に上から順に抽選を連続投稿できます。

↗

自動リアクション

トリガーに合わせてUnicode絵文字やサーバー固有絵文字を自動付与。管理画面からルールを管理できます。

≡

チャンネル案内

案内メッセージをチャンネル下部に維持。投稿内容や対象チャンネルをWebから編集できます。

◎

月カレンダー

予定を月表示で把握し、クリックで編集。単発予定はドラッグして日付を移動できます。

⌁

画像・メンション

画像付き投稿やロールメンションにも対応。Discordへ送られる内容をプレビューしながら設定できます。

WEB ADMIN

普段の設定は、コマンドではなく画面から。

Reactusはスラッシュコマンドだけでも操作できますが、日常の設定は `/reactus` から開く管理画面が中心です。 今後の予定、自動リアクション、Calendar設定、案内まで同じ場所で扱えます。

  • Discordのサーバー権限に応じて編集可能範囲を制御
  • 書き込めない設定は「閲覧のみ」として明確に表示
  • スマートフォンでも同じ機能を操作可能
  • 管理画面へのログインはDiscordから発行

GET STARTED

導入済みなら、最初に使うのは `/reactus` だけ。

  1. 1
    Discordで `/reactus`

    対象サーバーでコマンドを実行します。

  2. 2
    専用リンクを開く

    表示された「Reactus 管理画面を開く」を押します。

  3. 3
    ブラウザで設定

    予定や自動化をフォームから管理します。

管理画面を開くには、Discord上で「メッセージの管理」権限が必要です。発行リンクは10分間、ログイン後のセッションは30日間有効です。
